# ADR-001: Єдина черга та докази перед рекомендаціями
Status: Accepted for local foundation
Date: 2026-09-26

## Context
Локальний ПК, безкоштовний бюджет, Python/FastAPI база Gemini, слабка достовірність поточних fallback, потреба Android/Telegram.
## Decision
Зберегти Python/FastAPI та інтерфейс як основу. SQLite з міграціями й окремою робочою базою, незмінні версії джерел, журнал перевірок, явне підтвердження завдань. Зберігати помилку як помилку. Послідовна черга Ollama; спостереження і підпис транзакції розділені.
## Options considered
1. Переписати все на Node старого проєкту: втрата нових модулів і зайва міграція.
2. Додати важкий multi-agent framework: додаткові витрати й складність без гарантії доказовості.
3. Python моноліт з явними ролями й перевірками: обрано; простіше тестувати і розмістити.
## Consequences
Локальна SQLite не підходить для багатьох одночасних серверних worker; запускати один. Хмарний доступ потребує окремої авторизації. Для кожного джерела потрібен адаптер, а не довільне виконання команд моделлю.
## Actions
- Реєстр дозволених джерел та джерельних доказів.
- Безпечне відстеження без скидання завдань.
- Часові тести прогнозів та журнал помилок.
- Підтверджені історичні кейси; 500 — ціль дослідження, не декларація готовності.
