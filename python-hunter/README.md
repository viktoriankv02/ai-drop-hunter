# AI Crypto Hub & Hunter
Нова основа з проєкту Gemini. Локальний режим, Python 3.14, SQLite, Ollama.

## Запуск на Windows
За відсутності середовища спочатку виконайте у папці проєкту:

    py -3.14 -m venv .venv

Для вже встановленого проєкту: .\Start-Hunter.ps1.

    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe main.py

Адреса: http://127.0.0.1:4318
Старий застосунок на 4317 — окремий проєкт.

Робоча база створюється в data/workspace.sqlite. При першому запуску копіюються проєкти й завдання з наданої drop_hunter.db; початкова база не змінюється. Старі оцінки й позначки виконання не є перевіреними доказами; їхні значення зберігаються в legacy_json.

## Робота
- Джерела: CryptoRank перший, Incrypted другий. Telegram-канали додає лише користувач.
- «Цікаво»: додати до роботи й поставити дослідження в чергу.
- Щоденна перевірка: один раз на 24 години, поки сервер працює; пропущена перевірка ставиться в чергу при запуску.
- Якщо джерело блокує читання: помилка в журналі; на картці можна вставити матеріал із відкритої сторінки.
- Аналіз Ollama: локальний, послідовний, джерельні цитати перевіряються. Кроки є чернетками. Виправлення користувача передаються в наступний аналіз, не навчають ваги моделі.
- Ринок: реальні свічки Binance/OKX і експериментальний історичний діапазон з часовою контрольною вибіркою. Ще не ML-модель і не торговий сигнал.
- Автовиконавець вимкнений. Підписів, транзакцій і біржових ордерів застосунок не надсилає.

## Налаштування
HUNTER_DB — інша робоча SQLite; HUNTER_BACKGROUND=0 — без фонової черги для тестування.
OLLAMA_URL за замовчуванням http://127.0.0.1:11434; OLLAMA_MODEL=qwen3:4b-instruct.
Модель має бути встановлена окремо на D. Не публікуйте .env, базу чи профілі браузера.
