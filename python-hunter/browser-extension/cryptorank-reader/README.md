# CryptoRank Reader для нової версії Hunter

1. Відкрити chrome://extensions або edge://extensions; увімкнути режим розробника.
2. Завантажити розпаковане розширення з цієї папки.
3. Відкрити http://127.0.0.1:4318 у тому самому браузері.
4. Відкрити CryptoRank Drophunting, пройти перевірку самостійно, якщо сайт її показує.
5. Натиснути в розширенні «Зібрати проєкти зі сторінки». До 100 видимих посилань з відкритої сторінки, послідовно; приховані сторінки каталогу не завантажуються.

Збір зупиняється на challenge чи помилці. Розширення не читає API-панель, паролі або cookies. Це користувацький браузерний імпорт, не фоновий серверний доступ до CryptoRank. Працює лише коли браузер і локальний застосунок відкриті. Встановлення нової версії розширення в особистий браузер виконує користувач.
