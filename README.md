# AI Drop Hunter

Локальний вебзастосунок для дослідження криптопроєктів та обліку завдань. INK — перший пріоритет. AI Jobs не входять до runtime.

## Запуск

Потрібен Node.js 24+. Зовнішніх npm-залежностей немає.

```powershell
cd D:\Projects\ai-drop-hunter
npm test
npm start
```

Відкрийте http://127.0.0.1:4317. Зупинка: Ctrl+C. SQLite зберігається в `data/drop-hunter.sqlite`, виключена з Git. Для резервної копії зупиніть застосунок і скопіюйте папку `data`.

## Реалізовано

- Додавання проєктів, фільтр мереж, INK на початку списку.
- Ручне підтвердження джерела з обґрунтуванням, план завдань, запис доказу виконання.
- SQLite-транзакції та журнал дій; дані переживають перезапуск.
- HTTP API та адаптивний український інтерфейс.
- Лише loopback-доступ, перевірка Host/Origin і сесійний токен для змін.

Це локальна однокористувацька версія. Сесійний токен захищає від сторонніх вебсторінок, але не є авторизацією користувачів. Не публікуйте цей сервер через reverse proxy.

Рейтинг є евристикою сигналів, а не ймовірністю винагороди. Зараз доступний лише базовий сигнал ручної перевірки джерела; оцінка інших сигналів ще не підключена. Підтвердження джерела не підтверджує кампанію чи дроп. Виконання завдань — повідомлення користувача, без ончейн-перевірки.

## Наступні модулі

1. InkOpportunitySource: отримання офіційних матеріалів, походження та дата перевірки доказів.
2. Витягування умов, дедлайнів, ризиків та пояснюваний рейтинг.
3. Дозволені read-only агенти, scheduler і перевірка результатів.
4. Preview, симуляція та підпис транзакцій у гаманці; шаблони контрактів.
5. Авторизація для серверного розміщення, rewards та feedback memory.

Пошук довільних нових проєктів, check-in, гаманець і деплой контрактів ще не реалізовані. Приватні ключі не потрібні.

Змінено розширення імпорту для нативного TypeScript у Node. Старий показник confidence не використовується в API/UI, бо кількість посилань не доводить надійність джерел. Нові store, API, domain та UI написано для цього репозиторію.

INK metadata: https://docs.inkonchain.com/general/network-information (перевірено 2026-09-11). Інші мережі поки є категоріями дослідження, а не execution adapters.

Фінальний push у GitHub виконує власник після перегляду змін.
