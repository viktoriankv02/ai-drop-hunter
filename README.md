# AI Drop Hunter

Локальний український вебзастосунок для дослідження криптопроєктів, оцінки умов та обліку завдань. INK — перший пріоритет; AI Jobs не входять до runtime.

## Запуск

Node.js 24+. Для запуску й основних тестів зовнішніх npm-залежностей немає.

```powershell
cd D:\Projects\ai-drop-hunter
npm test
npm start
```

Відкрийте http://127.0.0.1:4317. Зупинка: Ctrl+C. Дані — у `data/drop-hunter.sqlite`, поза Git. Для резервної копії зупиніть сервер та скопіюйте всю папку `data`.

## Що означають оцінки

Бали описують повноту та придатність плану участі за оцінкою користувача, не ймовірність дропу. Ваги: відповідність умовам 30%, зрозумілість винагороди 25%, підтверджуваність виконання 20%, відомі витрати 15%, відповідність строкам 10%. Невідомі сигнали не додають балів; їхню частку показано окремо. Високі бали не скасовують високий ризик або минулий дедлайн.

Підтвердження джерела не підтверджує винагороду. Статус «оголошено» — висновок користувача із записаним доказом. Завдання виконуються вручну; застосунок зберігає повідомлення про виконання, без незалежного on-chain підтвердження.

## Обмеження

Це однокористувацька локальна версія. Токен запобігає змінам зі сторонніх вебсторінок, але не замінює авторизацію. Не публікуйте цей сервер через reverse proxy.

Каталог Ink apps потребує JavaScript: статичний адаптер чесно повертає помилку недостатнього тексту. Автоотримання працює лише для фіксованого списку офіційних URL; користувацькі URL сервер не завантажує.

LLM-провайдер, автоматичні check-in, підключення гаманця, симуляції та виконання транзакцій ще не реалізовані. Приватні ключі не потрібні. Інші мережі поки є категоріями дослідження.

## Перевірки

`npm test`: 25 unit/integration тести, включно зі збереженням після перезапуску, зміною джерел, часовими поясами, HTTP, повторюваністю та конфліктами розкладу.

`npm run test:browser`: повний сценарій у headless Edge, desktop/mobile, без змін робочої БД. Потребує встановленого Edge та пакета Playwright. Якщо Playwright розташований поза проєктом, задайте `PLAYWRIGHT_MODULE` як абсолютний шлях до пакета. Знімки зберігаються в `data/qa` і не комітяться.

4. Шаблони контрактів, авторизація для серверного розміщення, rewards та feedback memory.
