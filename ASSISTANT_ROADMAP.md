# Сервер, мобільний застосунок та помічник

## Рішення користувача
- Спільний сервер для щоденної роботи; ПК та Android — клієнти тих самих даних.
- Щоденна перевірка проєктів «Цікавить» і «У роботі».
- CryptoRank та Incrypted першими; офіційні сайти, X, Discord, Telegram, Reddit та власні спільноти.
- Сповіщення і взаємодія у вебдодатку та Telegram-боті.
- Переважно безкоштовні рішення; платні послуги лише після окремого рішення.
- Анімований робот-помічник з підказками, чатом та діями.

## Архітектура для реалізації
Сервер зберігає проєкти, версії умов і результати перевірок. Один щоденний планувальник із блокуванням повторного запуску. Відкриття клієнта оновлює дані та може запросити пропущену перевірку; ПК не запускає незалежний дубль серверної роботи.
Важливі зміни надходять до спільної черги повідомлень із захистом від повторної доставки у веб та Telegram. Виконані користувачем кроки не перезаписуються.
Для Android спочатку розробити встановлюваний вебзастосунок (PWA) зі спільним API; це не готовий APK.
Перед доступом з інтернету потрібні автентифікація, HTTPS, прив'язка Telegram chat ID і контроль доступу. Поточний localhost-сервер не готовий до публікації.
Соціальні джерела підключати через доступні дозволені інтерфейси. Не обходити закриті канали й обмеження; підписки користувача не означають автоматичного доступу застосунку. Не збирати паролі або токени через чат.
Безкоштовність цілодобового сервера, моделей і API соцмереж не гарантована. Спочатку встановити доступні ресурси й ліміти.
Майбутній чат із моделлю має бачити докази та поточні дані проєктів. Розмова Codex автоматично не синхронізується з ним.

## Реалізовано зараз
Локальний робот із підказками, вибраними проєктами, зведенням завдань і навігацією. Це інтерфейс на правилах, не LLM.
## Потребує підключення
Сервер, Android PWA, Telegram-бот, особисті спільноти, щоденний моніторинг вибраних проєктів і модель для чату.
